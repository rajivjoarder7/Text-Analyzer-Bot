## 🌟 **About the Project**
The **Text Analyzer Bot** is an AI-powered tool designed for **data scientists**, **machine learning enthusiasts**, and **NLP professionals**. It offers advanced capabilities for analyzing and summarizing text while answering complex questions based on a given context. Powered by state-of-the-art transformer models like **T5** and **PEGASUS**, it combines cutting-edge NLP research with user-friendly deployment. Its intuitive Gradio UI ensures an engaging experience for both technical and non-technical users.

---

🎯 **Key Features**:  
- **Text Summarization**: Generate concise summaries using the PEGASUS model.  
- **Question Answering**: Answer contextually relevant questions with the T5 model.  
- **Interactive UI**: Built using Gradio for an intuitive and seamless user experience.
- **GPU-Enabled Processing**: Optimized for fast execution on GPUs, making it ideal for large-scale or complex inputs.


---

## 🚀 **How It Works**
1. **Input**: Paste a paragraph (minimum 250 characters) into the app.  
2. **Summarization**: Generate a summary for text inputs exceeding 2000 characters.  
3. **Question Answering**: Ask questions about the input paragraph and receive AI-generated responses.  
4. **Real-Time Counters**: Displays word and character counts to ensure proper input length.

---

## 🛠️ **Tech Stack**
- **Language**: Python (3.9+)  
- **NLP Models**:  
  - **T5-Large**: For abstractive question answering.  
  - **PEGASUS-XSum**: For abstractive summarization.  
- **Frameworks**: Hugging Face Transformers, Gradio.
